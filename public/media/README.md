# Fallback media

Add the presentation fallback clips with these exact filenames:

- `skyline-rush.mp4`
- `taiwan-drone-flight.mp4`

Recommended delivery format:

- 1920×1080 (16:9)
- H.264 video
- `yuv420p` pixel format
- muted / no audio track required
- 15–25 seconds
- short loop with no hard visual jump at the cut

The slide keeps its designed placeholder visible when a file is absent or cannot be decoded.
